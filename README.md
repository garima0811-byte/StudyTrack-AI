# StudySync AI

StudySync AI is a student productivity dashboard designed to help students stay organized while studying.

## Features

- Task Manager
- Pomodoro Timer
- AI Study Assistant (Coming Soon)
- Dashboard Statistics
- Responsive Dark UI

## Built With

- HTML5
- CSS3
- JavaScript

## Future Improvements

- Gemini API Integration
- Local Storage
- Study Analytics
- Flashcards
- Quiz Generator
