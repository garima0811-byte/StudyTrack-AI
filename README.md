# StudyTrack AI

StudyTrack AI is a student productivity dashboard designed to help students stay organized while studying.

## Features

- Task Manager
- Pomodoro Timer
- AI Study Assistant (Work in progress)
- Dashboard Statistics
- Responsive Dark UI

## Built With

- HTML5
- CSS3
- JavaScript

## Future Improvements

- Gemini API Integration
- Local Storage
- Study Analytics
- Flashcards
- Quiz Generator
